# دليل تشغيل ورفع مشروع إدارة المخازن والمستودعات (مفصول بالكامل) 🚀

لقد تم بنجاح تقسيم كود تطبيق إدارة المخازن السحابية والفوترة إلى مشروعين منفصلين بالكامل لتمكينك من رفعهما واستضافتهما مجاناً:
1. **الفرونت اند (Frontend):** واجهة المستخدم المبنية بـ React + Vite + Tailwind CSS v4.
2. **الباك اند (Backend):** خادم API مستقل مبني بـ Node.js + Express مع دعم CORS وملفات البيئة `.env`.

---

## 📁 هيكلية المجلدات في المشروع

* `/frontend`: يحتوي على كود الواجهة الأمامية بالكامل بشكل مستقل.
* `/backend`: يحتوي على خادم الباك اند وقاعدة البيانات المؤقتة المستقلة بالكامل.

---

## 💻 أولاً: تشغيل المشروعين محلياً على جهازك (VSCode)

لتشغيل المشروع محلياً، افتح مجلد المشروع في VSCode واتبع الخطوات التالية:

### 1. تشغيل خادم الباك اند (Backend):
1. افتح نافذة Terminal جديدة وانتقل إلى مجلد الباك اند:
   ```bash
   cd backend
   ```
2. قم بتثبيت المكتبات المطلوبة:
   ```bash
   npm install
   ```
3. قم بإنشاء ملف `.env` (إذا لم يكن موجوداً) وتأكد من تحديد المنفذ (Port):
   ```env
   PORT=5000
   ```
4. شغل سيرفر الباك اند في وضع التطوير:
   ```bash
   npm run dev
   ```
   *سيعمل السيرفر الآن محلياً على الرابط: `http://localhost:5000`*

---

### 2. تشغيل الفرونت اند (Frontend):
1. افتح نافذة Terminal ثانية وانتقل إلى مجلد الفرونت اند:
   ```bash
   cd frontend
   ```
2. قم بتثبيت المكتبات المطلوبة:
   ```bash
   npm install
   ```
3. قم بتعديل ملف `.env` وتأكد من ربطه برابط الباك اند المحلي:
   ```env
   VITE_API_URL=http://localhost:5000
   ```
4. شغل تطبيق الفرونت اند:
   ```bash
   npm run dev
   ```
   *سيعمل تطبيق الفرونت اند محلياً على الرابط: `http://localhost:5173` ويمكنه الآن إرسال واستقبال البيانات من السيرفر بنجاح بفضل تفعيل الـ CORS!*

## 🌐 ثانياً: كيفية الرفع والاستضافة مجاناً (Deployment Guide)

### 1. استضافة الباك اند (Backend API) - مجاناً:
يمكنك رفع مجلد `backend` كشفرة مستقلة على GitHub واستضافته مجاناً على منصات مثل:
* [Render](https://render.com) (خيار ممتاز وسهل جداً للـ Node.js)
* [Railway](https://railway.app)
* [Koyeb](https://www.koyeb.com)

**طريقة الرفع على Render:**
1. ارفع مجلد `backend` فقط في مستودع مستقل على GitHub (Repository).
2. في Render، أنشئ **Web Service** جديدة واربطها بالمستودع.
3. اضبط الإعدادات التالية في لوحة تحكم Render:
   * **Build Command:** `npm install && npm run build`
   * **Start Command:** `npm run start`
4. في قسم **Environment Variables**، يمكنك إضافة متغيرات البيئة إن دعت الحاجة (مثل `PORT` وسيتم تحديدها تلقائياً من قبل Render).
5. بعد نجاح الرفع، سيعطيك Render رابطاً عاماً مثل: `https://your-backend-app.onrender.com`. **احفظ هذا الرابط لاستخدامه في الفرونت اند!**

---

### 2. استضافة الفرونت اند (Frontend UI) - مجاناً:
يمكنك رفع مجلد `frontend` كشفرة مستقلة واستضافته مجاناً على منصات استضافة المواقع الساكنة الرائدة مثل:
* [Vercel](https://vercel.com) (الأفضل والأسرع لمشاريع Vite)
* [Netlify](https://netlify.com)
* [GitHub Pages](https://pages.github.com)

**طريقة الرفع على Vercel أو Netlify:**
1. ارفع مجلد `frontend` فقط في مستودع مستقل على GitHub.
2. اربط حساب GitHub الخاص بك بالمنصة (Vercel أو Netlify).
3. اختر مستودع الفرونت اند واضبط الإعدادات التالية:
   * **Framework Preset:** `Vite`
   * **Build Command:** `npm run build`
   * **Output Directory:** `dist`
4. **💡 الأهم لحماية البيئة وربط الـ API:**
   في قسم **Environment Variables** بالمنصة، أضف المتغير التالي:
   * **Key:** `VITE_API_URL`
   * **Value:** `https://your-backend-app.onrender.com` *(رابط الباك اند النهائي الذي حصلت عليه من Render)*
5. اضغط **Deploy**. سيقوم الموقع بالبناء والربط فوراً، وبذلك ستحصل على موقع متكامل وسريع مجاناً 100%!

---

## 🛡️ أمن وحماية البيانات وعناوين الـ API
* تم إخفاء الروابط داخل الفرونت اند باستخدام `import.meta.env.VITE_API_URL` حتى لا يتم كتابة الروابط يدوياً (Hardcoded).
* تم استبعاد ملفات `.env` من الرفع في ملفات `.gitignore` المرفقة لحماية السيرفر من أي هجمات أو كشف للبيانات على مستودعات GitHub العامة.
